# Калькулятор себестоимости импортного товара

Пошагово спрашивает валюту и курс НБКР, товары (наименование, количество, цена,
страна происхождения, ставка пошлины и акциза), общие расходы и наценку.
Считает таможенную стоимость, пошлину, акциз, НДС на импорт, себестоимость
(всего и за единицу) и цену продажи. Результат на экране и в Excel `raschet_ДАТА.xlsx`.

## Запуск (PyCharm, Windows)
1. Скопируйте все `.py` файлы в папку проекта.
2. Один раз: `.\.venv\Scripts\python.exe -m pip install openpyxl`
3. Запуск: `.\.venv\Scripts\python.exe main.py`

## Как считается
- Таможенная стоимость = (цена × кол-во + доля доставки до границы) × курс
- Пошлина = таможенная стоимость × ставка (страны ЕАЭС — 0%)
- Акциз = (таможенная стоимость + пошлина) × ставка
- Таможенный сбор = таможенная стоимость × 0,4% (`SBOR_STAVKA`)
- НДС = (таможенная стоимость + пошлина + акциз + сбор) × 12%
- Себестоимость = тамож. стоимость + пошлина + акциз + сборы + прочие расходы
  (+ НДС, если организация не плательщик НДС)
- Цена продажи без НДС = ОКРУГЛВВЕРХ(себестоимость за ед. × (1 + наценка) ÷ (1 − налог с выручки); 0)
  (округление вверх до целого можно выключить)
  (плательщику НДС к цене для покупателя добавляется НДС)
- Налог с выручки (единый налог / налог с продаж) = выручка без НДС × ставка
- Прибыль = выручка без НДС − налог с выручки − себестоимость
- **Услуга нерезидента** (пошлины и таможни нет, общие расходы на неё не делятся):
  - НДН удерживается из суммы договора: база = сумма договора × курс
  - НДН платим сверху за свой счёт: база = сумма × курс ÷ (1 − ставка НДН)
  - НДН = база × ставка НДН (по умолчанию 10%, `NDN_STAVKA`)
  - НДС за нерезидента = база × 12% (к зачёту или в расход)
  - Себестоимость = цена поставщика + НДН (если сверху) + НДС (если не плательщик НДС)
  - **Формулы и ставки НДН/НДС по услугам нерезидентов проверьте по НК КР
    и договору об избежании двойного налогообложения.**
- Общие расходы делятся между товарами пропорционально их стоимости.

**Ставки (НДС 12%, пошлина, акциз) проверьте по действующему НК КР и ЕТТ ЕАЭС.**
НДС меняется в начале файла: `NDS_STAVKA` в `stavki.py`.

## Версия с окном (okno.py)
`okno.py` — то же самое, но в окне: поля сверху, таблица, итоги, кнопка «Сохранить в Excel».
Запуск: `.\.venv\Scripts\python.exe okno.py`

## Сборка в .exe
Дважды щёлкните `build_exe.bat` (или запустите его в терминале PyCharm: `.\build_exe.bat`).
Через 1–2 минуты появится `dist\Kalkulyator.exe` — его можно копировать на любой
компьютер с Windows, Python там не нужен. Антивирус иногда ругается на такие .exe —
это ложное срабатывание, добавьте файл в исключения.

## Считать в валюте
Галочка «Считать в валюте (без курса)» (в терминале — вопрос после валюты):
курс не нужен, все суммы и Excel — в валюте инвойса (как в калькуляции Dell в USD).

По умолчанию: не плательщик НДС (НДС входит в себестоимость), НДН по услугам — сверху.

## Файлы
| файл | что внутри |
|---|---|
| `stavki.py` | ставки НДС, НДН, сбора, список стран ЕАЭС |
| `raschet.py` | расчёт себестоимости, цены и прибыли |
| `vvod.py` | ввод с клавиатуры для терминальной версии |
| `otchet.py` | вывод на экран и сохранение в Excel |
| `main.py` | запуск в терминале |
| `okno.py` | окно (tkinter) |
